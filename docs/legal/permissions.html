Android Permissions Justification

Application: Visual Voicemail Assistant • Package ID: com.dalsc.voicemail_assistant • Author: Danish K (danishk.web.app)

This document details the functional necessity and privacy scope of every sensitive permission declared in AndroidManifest.xml for the Google Play Console Review Team and end users.

1. ROLE_CALL_SCREENING (CallScreeningService)

Core Purpose: Automated Call Assistant & Do Not Disturb (DND) Deflection.

Justification: Under Android 10+, background call management without the Call Screening Role is strictly forbidden. The app uses this role to screen incoming calls in real-time (< 30ms) against user-configured DND schedules and whitelist rules (starred contacts, repeat callers within 3 minutes, emergency services). When DND is active, unwanted calls are declined with setRejectCall(true), which triggers the carrier's conditional forward (*67* / *403*) to the user's dedicated relay number.

2. android.permission.CALL_PHONE

Core Purpose: Automated Carrier Forwarding Setup via MMI/USSD Codes.

Justification: Indian mobile carriers require dialing standard MMI codes (e.g., *403*DID for Jio, *67*DID# for Airtel/Vi/BSNL) to configure conditional call forwarding. This permission enables the app to dial these codes directly on the user's behalf via TelephonyManager.sendUssdRequest (with a fallback to intent), eliminating manual typing errors.

3. android.permission.READ_PHONE_STATE

Core Purpose: Multi-SIM / Dual-SIM Carrier Detection.

Justification: Over 90% of Indian smartphone users operate dual-SIM devices. The app requires this permission to identify the active subscription ID (SubscriptionManager) so that call-forwarding codes are dispatched to the exact carrier chosen by the user (e.g., SIM 1 Jio vs. SIM 2 Airtel).

4. android.permission.READ_CONTACTS

Core Purpose: Local Caller Identification & DND Exception Whitelisting.

Justification: Evaluated strictly on-device in native code to resolve caller phone numbers to contact names in the inbox and to allow starred contacts to bypass DND. Zero contact records or phonebook entries are ever transmitted to any external server.

5. android.permission.POST_NOTIFICATIONS

Core Purpose: Voicemail Arrival Alerts & Ongoing DND Status Notification.

Justification: Alerts the user when a voicemail is downloaded and provides an ongoing, persistent notification with a one-tap "Turn Off DND" button while call screening is active.

6. android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS

Core Purpose: Instantaneous FCM Wake-Up in Deep Doze Mode.

Justification: Without this exemption, Android's Doze mode and OEM battery managers (Xiaomi HyperOS, Realme UI, One UI) delay FCM push delivery for hours, preventing users from receiving timely voicemail alerts.

7. android.permission.ANSWER_PHONE_CALLS

Core Purpose: Experimental Mode 3 (Auto-Answer Assistant).

Justification: Enables the experimental on-device auto-answering mode via TelecomManager.acceptRingingCall(). This feature is clearly marked as experimental with clear disclaimers regarding acoustic limitations.
